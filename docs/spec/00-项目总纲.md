## 0. 你要做什么

从零构建 **DATO OCR**：一个 Windows 桌面截图工具，包含截图标注、长截图、离线 OCR、翻译、剪贴板历史五大功能。界面遵循 Apple 设计语言。macOS 为后续移植目标，第一版不实现但必须保留抽象层。

**当前仓库状态：空仓库，只有文档。所有代码从零开始。**

## 1. 铁律（不可自行更改的决策）

以下决策已由项目所有者拍板，实现时不得自作主张变更。若遇到技术上确实无法实现的情况，停下来说明原因，不要擅自换方案。

| # | 决策 | 说明 |
|---|---|---|
| 1 | **框架必须是 Tauri v2**，不得改用 Electron | 体积是核心诉求，Electron 会让成品从 40MB 涨到 200MB+ |
| 2 | **截图交互必须逐项对齐微信 Windows 版** | 详见 `02-截图模块.md` 的交互清单，每一条都是验收项 |
| 3 | **界面必须是 Apple 设计语言**，不得使用 Ant Design / Material UI / Element 等带有强烈自身风格的组件库 | 详见 `06-UI设计规范.md`，所有数值已给定 |
| 4 | **不得引入 GPL / AGPL 协议的依赖** | 本项目闭源发布。只能用 MIT / Apache-2.0 / BSD / MPL-2.0 |
| 5 | **长截图只做手动滚动模式**，不做自动滚动 | 兼容性优先 |
| 6 | **剪贴板默认全量记录**，不做智能跳过 | 黑名单功能默认关闭 |
| 7 | **OCR 默认引擎为 RapidOCR**，PaddleOCR 作为可选下载项 | 体积与兼容性优先 |
| 8 | **不得直接复制微信、Snipaste、PixPin 等闭源软件的代码** | 只对齐交互行为，实现用开源组件重写 |

## 5. 开发顺序（严格按此推进）

### M0 · 技术验证（3–5 天）— 不要跳过

目标：证明 Tauri 能干这活。产出一个丑但能跑的原型：

- [ ] Tauri v2 项目初始化，能打包出 exe
- [ ] 按 F1 弹出覆盖全屏的无边框置顶透明窗口

## 6. 全局约定

### 6.1 命名

- Rust：`snake_case` 文件与函数，`PascalCase` 类型
- TypeScript：`camelCase` 变量函数，`PascalCase` 组件与类型，文件名 `kebab-case.ts`，组件文件 `PascalCase.tsx`
- Tauri command：`snake_case`，动词开头，如 `capture_all_monitors`、`get_clipboard_page`
- Tauri event：`kebab-case`，`域-动作` 格式，如 `clipboard-changed`、`capture-finished`
- CSS 变量：`--cn-` 前缀，如 `--cn-color-accent`

### 6.2 错误处理

- Rust 侧统一使用 `thiserror` 定义 `AppError`，command 返回 `Result<T, AppError>`
- `AppError` 必须实现 `serde::Serialize`，前端拿到结构化错误 `{ code, message, detail }`
- **禁止 `unwrap()` / `expect()` 出现在任何可能失败的运行时路径**。仅允许在初始化阶段的不可恢复错误上使用，且必须写明原因
- 前端所有 `invoke` 走 `src/lib/ipc.ts` 封装，统一 catch 并转成 toast

### 6.3 日志

- Rust 用 `tracing` + `tracing-subscriber`，写入 `%APPDATA%/DATO OCR/logs/`，按天滚动，保留 7 天
- 前端用 `@tauri-apps/plugin-log` 转发到同一处
- 日志级别：release 默认 `info`，设置里可开 `debug`
- **日志中禁止出现剪贴板内容原文、OCR 识别结果原文、任何 API Key**

### 6.4 性能红线

| 指标 | 上限 |
|---|---|
| 冷启动到托盘图标出现 | 800 ms |
| 按下 F1 到遮罩窗口可交互 | 150 ms |
| 截图遮罩层拖拽帧率 | ≥ 60 fps |
| 空闲常驻内存 | 80 MB |
| 剪贴板搜索响应（3 万条） | 100 ms |
| 安装包体积 | 40 MB |

超出红线视为缺陷，必须优化后才能进入下一阶段。

### 6.5 无障碍与降级

- 所有可点击元素必须有 `cursor: pointer` 和可见焦点环
- 尊重 `prefers-reduced-motion`，命中时把所有动画时长降为 0
- 检测系统透明度设置（Windows：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\EnableTransparency`）和省电模式，任一命中则关闭玻璃效果
- 全部界面文字对比度 ≥ 4.5:1
- 图标一律用 SVG（Lucide 图标集），**禁止用 emoji 当图标**

### 6.6 国际化

第一版只出简体中文，但所有界面文案必须走 i18n（`react-i18next`），不得硬编码在组件里。英文文案同步写好，方便后续开英文版。
