# DATO COR 方案总览

> 这份文档是写给人看的。不含代码、不含技术黑话，读完你就知道这软件做出来是什么样子、分几步做、每步要多久。
> 技术细节在 `docs/spec/` 里，那是给 AI 看的。

---

## 一、这是个什么软件

一句话：**一个截图工具，顺便把截完图之后你最常干的几件事都办了。**

你截了一张图，接下来通常会想干嘛？

- 想在上面画个圈标一下 → 标注
- 想把图里的字抠出来 → 文字识别
- 图是英文的，看不懂 → 翻译
- 想钉在屏幕上边看边抄 → 贴图
- 内容太长一屏截不完 → 长截图
- 刚才复制的东西被覆盖了，想找回来 → 剪贴板历史

DATO COR 就是把这六件事装进一个 40MB 的软件里，而且截图这一环的手感，跟你天天在用的微信截图一模一样。

---

## 二、体积为什么能做到 40MB

这是这个方案里最值钱的一个决定，所以单独说一下。

市面上大部分这类软件用的是 Electron，它的做法是**把一整个 Chrome 浏览器打包进你的软件里**。所以哪怕你只写了一个"Hello World"，装完也有 85MB。真实产品普遍在 130–250MB。

我们用的 Tauri 换了个思路：**你的 Windows 里本来就装了 Edge 浏览器，直接借用它的内核**，软件本身只装自己的那部分。实测对比（同一个软件的两个版本）：

| | Tauri 版 | Electron 版 |
|---|---|---|
| Windows 安装包 | 12 MB | 201 MB |
| 开机后常驻内存 | 42 MB | 187 MB |
| 双击到窗口出现 | 0.38 秒 | 1.42 秒 |

截图工具是**天天挂在后台**的，内存和启动速度的差距你每天都能感觉到。

**那微信那套截图交互怎么办？** 查证过了，不受影响。目前最像微信的开源截图组件叫 `react-screenshots`（方框、圆圈、箭头、画笔、马赛克、文字全都有），它本身是个独立的网页组件，跟 Electron 没有绑定关系。而底层"抓屏幕画面"的核心库叫 `xcap`，Electron 版和 Tauri 版用的是同一个，作者还是同一个人。

已经有人这么干了，而且跑通了：

- **EcoPaste** — Tauri 做的剪贴板管理器，对标 Mac 上的 Paste，安装包 7.3MB
- **WeCut** — 在 EcoPaste 基础上加了截图标注、OCR 提取文字、贴图钉屏，形态跟我们要做的几乎一样
- **Snow Shot** — Tauri 截图工具

DATO COR 会站在这些项目的肩膀上。

**代价是什么？** 两条，都不致命：

1. 每次改完代码要等编译，Tauri 大概 20 秒起步，Electron 几秒钟。对开发效率有影响，对成品没影响。
2. macOS 上借用的是 Safari 内核，跟 Windows 的 Edge 内核在极少数特效上表现不一样。液态玻璃里最花哨的那种"折射变形"效果，Safari 支持不完整。规格文档里已经给了替代做法。

## 三、界面长什么样

### 整体形态

一个**正经的主窗口**，左边是毛玻璃侧边栏，右边是内容区。侧边栏四项：

```
┌─────────────┬──────────────────────────────┐
│             │                              │
│  ● 截图库    │                              │
│  ● 剪贴板    │        内容区                 │
│  ● 识字记录  │                              │
│  ● 设置      │                              │
│             │                              │
│  ─────────  │                              │
│  ⌘ 快捷键    │                              │
└─────────────┴──────────────────────────────┘
```

平时这个窗口关着，托盘里留个图标。要截图直接按 F1，不用先打开软件。

### 苹果味体现在哪

不是"看起来有点像"，是有具体数值的：

| 元素 | 做法 |
|---|---|
| 窗口外框 | 用 Windows 自带的亚克力材质，能真实透出你的桌面壁纸 |
| 侧边栏 | 半透明毛玻璃，模糊半径 20px，饱和度提到 180%（这是苹果的真实参数） |
| 圆角 | 窗口 12px、卡片 10px、按钮 8px，关键面板用"连续圆角"（苹果那种没有拐点的圆） |
| 主色 | #007AFF（苹果系统蓝，浅色模式）/ #0A84FF（深色模式） |
| 中文字体 | 内嵌 MiSans（小米开源，免费商用，字形最接近苹方）。微软雅黑一用上去苹果味就全没了 |
| 动效 | 面板滑出用 iOS 弹窗的那条曲线，鼠标悬停 150ms，按下缩到 97% |
| 分隔线 | 0.5px（不是 1px），这是苹果和其他系统最容易分辨的细节之一 |

**旧电脑怎么办？** 软件会检测两件事：系统里的"透明效果"开关是否关闭、当前是否在省电模式。任意一条命中，自动退回不透明的干净底色。功能一点不少，只是不闪了。

## 四、五个功能分别做成什么样

### 4.1 截图（核心中的核心）

**手感 100% 对齐微信 Windows 版**，包括这些你可能没意识到但天天在用的细节：

- 按下 F1，屏幕瞬间压暗一层，没有过渡动画（微信就是瞬间的，加动画反而慢）
- 鼠标移到哪个窗口上，就自动把那个窗口框起来。移到窗口里的某个区块上（比如聊天框、按钮组），能框住那个区块
- 按住拖拽自己框，框的过程中左上角实时显示 `1280 × 720`
- 鼠标旁边跟着一个放大镜，显示当前像素点的坐标和颜色值
- 框完松手，选区边上出现 8 个小方点，随便拖哪个都能调大小
- 工具条出现在选区正下方、右对齐。如果选区靠近屏幕底部，工具条自动跑到选区上方
- Enter 完成，Esc 取消，右键取消，双击选区内部也是完成
- Ctrl+Z 撤销上一笔标注
- 方向键微调选区 1 像素，按住 Shift 一次挪 10 像素
- 选区边缘靠近窗口边界时，自动吸附上去

**工具条**在微信那一排（方框、圆圈、箭头、画笔、马赛克、文字、撤销、保存、取消、完成）的基础上，多加四个图标：

| 新增 | 作用 |
|---|---|
| 识字 | 直接把选区里的文字抠出来 |
| 翻译 | 抠出文字并翻译 |
| 长截图 | 切到滚动采集模式 |
| 贴图 | 把选区钉在屏幕最上层 |

除此之外一个按钮都不多加。

**贴图**（微信没有，Snipaste 的招牌功能）：截完图按一下，这张图变成一个悬浮在所有窗口之上的小窗，可以拖、可以滚轮缩放、可以调透明度、可以双击隐藏。抄东西的时候极其好用。

### 4.2 长截图

你框好范围，然后**自己滚鼠标滚轮**，软件在后面默默每滚一下拍一张，实时拼接，旁边显示一条缩略预览。滚完按 Enter 出图。

为什么不做全自动？自动滚动看着爽，但遇到带悬浮导航栏的网页、滚动步长不规则的软件，经常拼歪或者漏行。手动滚兼容性最好，什么窗口都能拍。

拼接这块有两个细节会处理好：

- **重叠区匹配** — 拿上一张的底部一条像素当模板，在新一张里找它出现在哪，找到了就从那接上。所以你滚快滚慢、滚多滚少都不影响
- **固定头部识别** — 如果连续几张图的顶部区域一模一样，判定那是个悬浮导航栏，后面的图自动把它裁掉，不会在长图里重复出现十遍

### 4.3 文字识别

**默认离线**。软件内置 RapidOCR 引擎，30MB，不联网也能用，识别一张普通截图大概半秒。任何老电脑都能跑（PaddleOCR 那种要求 CPU 支持 AVX 指令集，奔腾赛扬直接用不了，所以不选它当默认）。

设置里有个"下载高精度引擎"按钮，想要更准（尤其手写体、艺术字）的用户自己点一下，再下 250MB 的 PaddleOCR。默认不装，不占体积。

识别结果不是把字一股脑倒出来，会做**段落还原**：按位置把文字块分行、分段，该换行的换行，该合并的合并。识别界面上，图片和文字左右对开，鼠标划过文字会在图上高亮对应位置。

### 4.4 翻译

内置三个免费翻译源，一个不通自动换下一个，保证开箱能用。想要更好质量的，在设置里填自己的 DeepL 或者 OpenAI 密钥。

用法有三种：截图后点翻译、选中屏幕上的文字划词翻译、剪贴板里的内容右键翻译。

### 4.5 剪贴板

你复制的所有东西——文字、网页片段、图片、文件——全部自动存下来。

**按 Alt+V，从屏幕底部滑出一条横向卡片列表**，就是 Mac 上 Paste 那个样子。左右方向键选，Enter 粘贴，直接敲字就是搜索。不喜欢横的，设置里能换成鼠标旁边弹出的竖版小面板。

每张卡片显示：内容预览、来源软件的图标、什么时候复制的。

能干的事：置顶、收藏、加备注、分组、拖出去、复制成纯文本、直接翻译、图片直接识字。

搜索用的是 SQLite 全文索引，几万条记录也是瞬间出结果。

**关于隐私**：按你的要求，默认全量记录，一条不漏，你自己手动删。设置里有个默认关闭的"应用黑名单"，哪天你想屏蔽密码管理器之类的，开一下就行。所有数据只存在你电脑上，不上传任何地方。

## 五、Mac 怎么留后路

界面代码从第一天起就是两边共用的，不写任何 Windows 专属的界面逻辑。

只有四样东西是贴着操作系统的，这四样会被单独抽成一层，现在只填 Windows 的实现，接口先定好：

1. 抓屏幕画面
2. 枚举窗口位置（用于自动框选）
3. 监听剪贴板变化
4. 注册全局快捷键 + 窗口毛玻璃特效

以后做 Mac 版，把这四个填上就行，界面部分零改动。工作量大概是两周，而不是重做。

## 六、分几步做，各要多久

| 阶段 | 做什么 | 工期 | 做完能干嘛 |
|---|---|---|---|
| M0 | 技术验证 | 3–5 天 | 能框选、能标注、能复制到剪贴板的最简版本。这一步是为了在投入前确认 Tauri 这条路走得通 |
| M1 | 截图核心 | 2–3 周 | 微信那套完整手感全部到位：窗口检测、放大镜、8点调整、多显示器 |
| M2 | 标注 + 贴图 | 1 周 | 画笔工具全套 + 钉屏 |
| M3 | 识字 + 翻译 | 1 周 | F3 一按出文字 |
| M4 | 剪贴板 | 2 周 | 底部卡片面板 + 搜索 + 置顶收藏 |
| M5 | 长截图 | 1 周 | 滚动拼接 |
| M6 | 主窗口 + 设置 + 打磨 | 1.5 周 | 苹果风界面全部落地，性能调优 |
| M7 | 打包发布 | 3 天 | 安装包、自动更新、开机自启 |

**合计约 10 周**能出第一个正式可用版本。

M0 那 3–5 天很重要，别跳过。如果 Tauri 在你的机器上有什么意外情况，那时候掉头成本最低。

## 七、第二阶段：账号和 iPhone 同步

这部分**不在第一版里**，但架构上会提前留好位置（剪贴板的数据表里预留同步字段，不返工）。

先说清楚现实情况，避免期待落空：

**苹果的"隔空剪贴板"是锁死在苹果生态内部的**，Windows 电脑没有任何合法途径接进去。想要"手机复制、电脑就有"，唯一的路是：

```
iPhone 上装一个我们自己做的小 App
        ↓  （复制的内容加密上传）
    我们自己的服务器
        ↓  （推送给电脑）
   Windows 上的 DATO COR
```

**"用 Apple 账户登录"这个功能本身可以做**，苹果开放了标准接口。但它只能用来证明"你是你"，不能拿它存数据。数据得存在我们自己的服务器上。

**短信验证码提示**同理，iPhone 上的小 App 拿到验证码之后转发给电脑。

要做这些，需要准备：

| 项 | 成本 |
|---|---|
| 苹果开发者账号 | 688 元/年 |
| 服务器 | 起步 30–100 元/月 |
| App Store 审核 | 首次 1–2 周，可能被打回 |
| 额外开发量 | iOS App 3–4 周 + 服务端 2–3 周 + Windows 端对接 1 周 |

技术方案（端到端加密、密钥怎么派发、离线消息怎么补）已经写在 `docs/spec/09-第二阶段-账号与手机同步.md` 里了，等第一版跑起来再启动。

**有个过渡方案**可以考虑：只做局域网同步，不要服务器。手机和电脑连同一个 WiFi 时自动互通，免费、数据不出家门、不用过审核（通过 App Store 上架一个纯本地功能的 App 容易得多）。缺点是出门在外就不同步了，而且 iPhone 后台限制严，验证码转发会有延迟。这个方案的开发量大概是完整方案的三分之一。

## 八、有哪些风险

| 风险 | 影响 | 怎么办 |
|---|---|---|
| Tauri 的窗口在某些机器上有透明/圆角显示问题 | 中 | M0 阶段专门验证；准备好不透明降级方案 |
| 多显示器 + 不同缩放比例下截图错位 | 高 | 这是所有截图软件最容易翻车的地方，M1 阶段必须在混合 DPI 环境实测 |
| 液态玻璃在 macOS 的 Safari 内核上表现不同 | 低 | 规格里已给两套实现，Windows 用高级版，macOS 用保守版 |
| 免费翻译接口失效 | 低 | 三源自动切换，且支持自填密钥 |
| 长截图在某些软件上拼不好 | 中 | 拼接失败时给出提示并保留已采集的分帧，用户可手动挑选 |
| 微信截图的部分交互属于产品设计，直接抄代码有法律风险 | 低 | 只对齐交互行为，代码用开源组件重写。这是行业通行做法 |
